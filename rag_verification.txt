# PROJECT 4 --- LEGACY

## Project Identity

Legacy is a persistent life-trajectory and memory agent.

It transforms unstructured daily reflections, workspace activity, and
external API events into a structured behavioral knowledge graph.

The problem Legacy addresses is the "Say/Do Gap."

Traditional LLM memory often remembers what a person says. Legacy
attempts to compare stated intentions with observable actions and
evidence.

It shifts memory from passive fact retrieval toward evidence-grounded
behavioral reasoning.

---

## Structured Memory Architecture

Legacy does not use flat chat-history memory.

It builds a behavioral graph.

For example:

GOAL: Learn AI

CLAIM: I am consistently studying AI

ACTION: Completed an AI project task

EVIDENCE: Verified GitHub commit

CONTRADICTION: Most observed work over a period was unrelated to the
stated goal

This structure allows the system to reason about relationships between
intentions and behavior.

---

## MCP Integration

Legacy exposes memory capabilities through an MCP server.

Conceptual tools include: - remember - recall - distill

This allows IDE agents such as Cursor or Claude Code to interact with
the memory system.

The broader idea is to make persistent behavioral context available
inside the developer's natural workflow.

## Autonomous Agent Behavior

Legacy is both: - A reactive FastAPI service - An autonomous background
reasoning system

`agent_tick()` evaluates whether enough new context exists to justify
generating a hypothesis.

The system therefore does not require every reasoning action to
originate from a direct user chat message.

This is why Legacy should be described as an agent rather than only a
RAG chatbot.

---

## Graph Completion Instead of Basic Similarity RAG

Legacy does not rely only on: Question → Vector similarity → Top-k
chunks → LLM

Instead, it uses graph-oriented completion and traversal.

Reasoning engines query relationships between typed nodes.

Example conceptual query:

"Find CLAIM nodes in a domain that are not supported by ACTION or
EVIDENCE nodes linked to the same goal."

The advantage is relational reasoning.
